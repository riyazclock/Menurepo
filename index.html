Going Live
  1. Scan your real dishes. Use an app like Polycam, Luma AI, or KIRI Engine (free, iPhone/Android) — plate the dish, walk around it for 20–30 seconds, export as .glb.
  2. Swap the model. Replace the demo Avocado file above with each dish's .glb, one card per menu item.
  3. Host the page. Publish this file anywhere (Netlify, Vercel, or your existing website) — you'll get a real URL.
  4. Generate your real QR. Point it at that live URL instead of the placeholder above, and print it on the menu card.
  5. Test on-site. AR "view in your space" works in Safari on iPhone and Chrome on Android — no app install needed.
